Политика конфиденциальности
«Закваска и Хлеб»

Дата вступления в силу: 20 сентября 2026 года

1. Какие данные собирает приложение

Приложение «Закваска и Хлеб» не собирает, не передаёт и не хранит на внешних серверах никаких персональных данных пользователя.

Приложение не запрашивает регистрацию, не использует аккаунты, не собирает идентификаторы устройства, не применяет рекламные и аналитические системы.

2. Данные, создаваемые пользователем

Отметки о выполненных действиях, замеры, настройки, текстовые записи и фотографии, которые пользователь добавляет в приложении, сохраняются исключительно в локальном хранилище устройства и не покидают его.

Пользователь может в любой момент удалить эти данные через настройки приложения или удалив приложение с устройства.

3. Разрешения

  • Доступ к камере и галерее — только для того, чтобы пользователь мог добавить собственную фотографию к записи. Снимки остаются на устройстве.
  • Показ уведомлений — только для напоминаний о кормлении закваски. Напоминания формируются на самом устройстве и никуда не отправляются.

4. Передача третьим лицам

Передача данных третьим лицам не осуществляется, так как данные не покидают устройство пользователя.

5. Дети

Приложение не предназначено для сбора данных о детях и не собирает данные ни о каких категориях пользователей.

6. Изменения

При изменении политики новая редакция публикуется по этому же адресу с указанием даты вступления в силу.
